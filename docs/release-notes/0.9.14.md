> [!NOTE]
> **The headline of this release is a switch for people who have no television.**
> Couch Session can now be used purely for HDR and performance, with everything about sessions put away. If that is you, pick **At my desk only** the first time it opens.

## 🖱️ New: use it at a desk only

A single switch under **General ▸ How you use this** turns off the couch half of the app.

- **Display & Audio and Controller leave the window.** So do the session hotkeys, the guide button trigger, the start-a-session settings, and the Start button in the footer.
- **HDR and performance stay**, and are described in terms of a running game rather than a session. The power plan and notification silencing now apply while a game is running.
- **HDR switches to per game** when you turn the mode on, because that is what most people without a television came for.
- **Nothing is lost.** Your display, audio and controller settings are remembered and come straight back if you turn it off.

The first run now asks which way you use the app instead of pointing at a page, and either answer can be changed later.

## 🔏 Fixed: start with Windows, after the app moves

Windows records where the executable is, not what it is called, so moving Couch Session left the sign-in launch pointing at a folder that no longer existed. It failed silently at every sign-in while the setting still read as on.

Every launch now checks where the startup entry points and repairs it if the app has moved, and says so when it does.

## 🌈 Fixed: HDR

- **HDR already on when a ticked game starts now switches off when that game closes.** Previously it was left alone, so HDR turned on for a film and forgotten stayed on all evening.
- **Steam applications are kept out of the game list.** Wallpaper Engine in particular runs all day, which made it a permanent candidate for "the game you are playing" and taught Smart HDR that your wallpaper wants HDR. Anything missed can still be added by hand with **Browse**.
- **Smart HDR is marked as recommended**, since it is what keeps the list current.

## ✨ Fixed: the window

- **The settings-at-a-glance grid no longer flickers** when the window is resized or maximized. A rebuild and the layout pass that completes it were repainting the window twice, a frame apart.
- **No more visible settling on startup.** The same layout pass ran three times, twice of them after the window was already on screen.
- **The footer no longer breaks** when the main button comes and goes.
- **The guide banner can be dismissed.** It returns after an update or a settings reset.
- **The power plan picker is hidden until its parent is on**, rather than shown greyed out.

## ✍️ Wording

Several descriptions said things the code did not do, and have been corrected:

- HDR was described as only ever switching off what it had turned on. Smart HDR makes that untrue, and it ships on.
- "A game from the list below" was really "a game you have ticked below", which is a different set on a list of every game you own.
- The notification row that mentions UAC and the firewall no longer says so in the mode where neither exists.

## ⚠️ Known issues

- **Moving the app breaks "Start with Windows" for one sign-in.** It repairs itself the next time Couch Session runs and tells you it did, but a move followed by a restart misses that one.
- **Exclusive-fullscreen games minimize when the session prompt appears.** Windows does that itself when such a game loses focus. Borderless fullscreen avoids it.
- **HDR can quietly do nothing on a display that supports it.** HDR is only switched when Windows reports the display as capable, and Windows does not always agree with the display.
- **Some windows do not go back where they were.** OBS is a reliable example.
- **The display can be slow to sleep while a controller is connected.** The app lets go after about ninety seconds of an untouched pad.

## 💻 Getting it

> [!WARNING]
> **Windows will warn you the first time.** `CouchSession.exe` is not code signed, so SmartScreen shows *"Windows protected your PC"*. Click **More info**, then **Run anyway**.

Windows 10 or 11. No installer and no runtime to install. Download `CouchSession.exe` below and run it.

If you are already running 0.9.13, the app will offer this to you on its own.
