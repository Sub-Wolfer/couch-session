> [!IMPORTANT]
> **This is the first published build of Couch Session.**
> It is in daily use on the machine it was written on, but that is one PC, one TV and two controllers. **Expect bugs.** Right now a bug report is worth more than a feature request.

## 🐛 Reporting a bug

> [!TIP]
> Use the **Report a bug** button in the app's footer. It writes one file to your desktop with the log, your settings and your display and audio details, then opens the issue page for you to attach it. That file is almost always where the answer is hiding.

Otherwise, [open an issue](https://github.com/Sub-Wolfer/couch-session/issues) and attach `%AppData%\CouchSession\couchsession.log`.

Especially useful to hear about:

- **Controllers other than Xbox pads and the PS5 DualSense.** Everything else should work, but only those two have been tested. A DualShock 4, a Switch Pro, an 8BitDo: a report either way is genuinely useful.
- **Games that behave oddly around the session prompt**, particularly exclusive-fullscreen ones.
- **Anything the app tells you that turns out not to be true.** Wrong text is treated here as a real bug.

## 💻 Getting it

> [!NOTE]
> **Windows 10 or 11. No installer and no runtime to install.**
> Download `CouchSession.exe` below and run it. Settings live in `%AppData%\CouchSession` and nothing is written anywhere else.

> [!WARNING]
> **Windows will warn you the first time.** `CouchSession.exe` is not code signed, so SmartScreen shows *"Windows protected your PC"*. Click **More info**, then **Run anyway**. Your antivirus may want a word too, for the same reason.

**Why it isn't signed.** A code signing certificate costs a few hundred dollars a year, renewed forever, and a new certificate carries no reputation with SmartScreen until enough people have downloaded it for Microsoft to trust it. For a free tool written by one person, that is a recurring bill to make a warning go away. It may be worth it later. It isn't yet.

**You don't have to take it on trust.** This build was produced by GitHub from the source in this repository, on their machines, from the exact commit this tag points at. The [build log](https://github.com/Sub-Wolfer/couch-session/actions) is public, so you can read what went into the file you are downloading. Or [build it yourself](https://github.com/Sub-Wolfer/couch-session#-building-it-yourself); it is two commands.

**Steam** is needed for the Big Picture half of a session. The HDR and display features work without it.
