> [!IMPORTANT]
> **This is the first published build of Couch Session.**
> It is in daily use on the machine it was written on, but that is one PC, one television and two controllers. **Expect bugs.** Right now a bug report is worth more than a feature request.

## 🐛 Reporting a bug

> [!TIP]
> Use the **Report a bug** button in the app's footer. It writes one file to your desktop with the log, your settings and your display and audio details, then opens the issue page for you to attach it. That file is almost always where the answer is hiding.

Otherwise, [open an issue](https://github.com/Sub-Wolfer/couch-session/issues) and attach `%AppData%\CouchSession\couchsession.log`.

Especially useful to hear about:

- **Controllers other than Xbox pads and the PS5 DualSense.** Everything else should work, but only those two have been tested. A DualShock 4, a Switch Pro, an 8BitDo: a report either way is genuinely useful.
- **Games that behave oddly around the session prompt**, particularly exclusive-fullscreen ones.
- **Anything the app tells you that turns out not to be true.** Wrong text is treated here as a real bug.

## ⚠️ Known issues

> [!WARNING]
> **A game that ignores the request to close is ended outright after 8 seconds, and unsaved progress goes with it.**
> Closing asks the game politely first, the same way <kbd>Alt</kbd>+<kbd>F4</kbd> does, so most titles save and exit cleanly. A game paused on its own dialog, mid-cutscene, or simply slow does not get longer. The confirmation dialog does not currently mention this.

- **Exclusive-fullscreen games minimize when the session prompt appears.** Windows does that itself the moment such a game loses focus, and it cannot be avoided while also taking the controller away from the game. Setting a game to *borderless* fullscreen avoids it entirely.
- **HDR can quietly do nothing on a display that supports it.** The app only switches HDR when Windows reports the display as capable, and Windows does not always agree with the display itself. Nothing on screen says so, there is no way to overrule it in this build, and the log is the only place it is recorded.
- **Some windows do not go back where they were.** OBS is a reliable example. A window moved to a second monitor shortly before a session may also come back on the wrong one. Under investigation; the log now records both cases.
- **The display can be slow to sleep while a controller is connected.** A pad that streams continuously, as a DualSense does even sitting still, holds Windows' idle timer open. The app lets go after about 90 seconds of a genuinely untouched controller.
- **Couch audio set to the same device you already use does nothing.** There is nothing to move and nothing to restore. The app says so once per run and points at the setting.
- **A TV's audio output only appears in the list while the TV is on.** One seen before stays selectable, marked as off, so it can be chosen with the set cold.

## 🔊 Sound

- **A game left running on the desktop is now actually muted.** It never was. One missing attribute on the Windows audio interop meant the app misread every answer Windows gave it, concluded that every audio session on the machine belonged to Windows itself, and skipped all of them.
- The same fault meant games were recorded as muted without ever being muted, so the startup recovery never had anything to undo.
- A mute that finds nothing now reports what it looked at, so a failure names itself instead of being silent.

## 🖥️ Displays

- **A monitor detached for a session is put back after a crash.** If the app was killed mid-session, the monitors it had detached stayed off, and the next launch read the reduced desktop as normal. One hard stop cost a monitor permanently, and every session afterwards agreed with it.
- **"Swap to desktop" no longer closes Big Picture.** It left your game running but took its shell away, so Steam dropped out of Big Picture mode, the guide button stopped opening the overlay, and resuming never got back to where it started.
- A television chosen while switched off is no longer saved with "disconnected" stuck to its name. Settings already carrying that repair themselves on startup.

## 🔄 Updates

- **The update check works.** It failed every time and blamed your network. A repository with no releases answers with the same code as one that does not exist, and the app reported the wrong one of those.
- A new version found while you are playing now waits until the session is over and no game is running, rather than putting a notice on the television mid-game.

## 🔔 Notifications

- Problem messages stay up for fifteen seconds instead of seven, which is long enough to read and act on.
- A long notification title wraps instead of being cut off mid-word.
- The couch-audio warning explains why it appeared and how to stop it, once per run rather than at the start of every session.
- A failure to switch HDR is filed under *when something goes wrong* rather than *when something you pressed is done*, so the switch that silences it actually does.

## ✍️ Wording

Sixteen pieces of text said something the code did not do. Every one now matches. The ones that mattered:

- **Closing Big Picture closes your running game.** Nothing said so, and the settings page said the opposite, in bold.
- The disconnect card promised your game keeps running, directly above a dropdown set to close it.
- The About page promised one press moves your HDR, resolution and power plan, when all three ship switched off.
- The update card claimed it would wait for your session to end while nothing waited.
- *"No displays found, is the TV on?"* appeared in the one situation where switching the TV on changes nothing.
- The README promised that closing the app restores your Xbox Game Bar. It does not, and nothing does.

## 🔧 Under the hood

- The session prompt no longer builds and discards a full-screen image thirty times a second.
- Tooltips are released when a settings page rebuilds, instead of accumulating for the life of the window.
- Settings-at-a-glance headings are easier to pick out.
- Every message the app speaks now lives in one file, including the session start and end messages, which did not.

## 💻 Getting it

> [!NOTE]
> **Windows 10 or 11. No installer and no runtime to install.**
> Download `CouchSession.exe` below and run it. Settings live in `%AppData%\CouchSession` and nothing is written anywhere else.
